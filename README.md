# 榆木记账

开源的 iOS 记账软件，SwiftUI 原生开发。

## 功能
- 记收入 / 支出：分类、金额、支付方式（微信/支付宝/现金/银行卡）、日期、备注
- 首页看本月结余、收入、支出，按月翻页
- 点一笔账单可编辑，左滑可删除，支持搜索
- 月预算设置与剩余进度
- 导出本月 CSV
- 数据保存在手机本地（UserDefaults），不联网、不上传

## 环境
- macOS + Xcode 15 或以上
- iOS 17.0 或以上
